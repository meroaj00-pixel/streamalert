¿Cómo convertir esto en APK?

Puedes convertir esta aplicación HTML/JS en un archivo **.APK** nativo para Android sin modificar tu código web usando **Capacitor** de Ionic.

Paso 1: Inicializar proyecto 
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
Paso 2: Configurar Capacitor 
npx cap init "StreamAlert" "com.streamalert.app"

Guarda este archivo HTML como index.html en la carpeta public o root.

Paso 3: Generar APK en Android Studio 
npx cap add android
npx cap open android

En Android Studio selecciona: Build > Build Bundle(s) / APK(s) > Build APK(s).
